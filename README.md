# CS-300 Data Structures and Algorithms

## Project Overview

In this course, I worked on two projects that focused on using data structures and algorithms to solve problems efficiently. The main goal was to develop a course advising program for ABCU that would allow academic advisors to load course information, display a list of courses in alphanumeric order, and search for individual courses and their prerequisites. In Project One, I evaluated different data structures to determine which would work best for the program. In Project Two, I used what I learned to develop a working C++ application using a binary search tree.

## How did you approach the problem? Consider why data structures are important to understand.

I approached the problem by first comparing vectors, hash tables, and binary search trees. I analyzed their run-time and memory requirements and considered how efficiently each structure could store, search, and organize course information. I chose a binary search tree because it allows courses to be displayed in alphanumeric order through an in-order traversal. This project helped me understand that choosing the right data structure is important because it affects a program's performance, efficiency, and overall design.

## How did you overcome any roadblocks you encountered while going through the activities or project?

One challenge I encountered was understanding how to implement a binary search tree and use it to organize course information correctly. I also had to make sure the program could read the course data from a file, store the information, and display the correct results when a user selected a menu option. I worked through these challenges by breaking the program into smaller functions, reviewing my logic, and testing the application in Eclipse. Seeing the program successfully load all eight courses and display them correctly helped me confirm that my implementation was working.

## How has your work on this project expanded your approach to designing software and developing programs?

These projects taught me to spend more time planning a program before beginning to write code. Instead of immediately choosing a solution, I now understand the importance of comparing different approaches and considering their advantages and disadvantages. Analyzing time complexity and memory usage helped me recognize how design decisions can affect performance, especially when working with larger amounts of data. I also gained more experience translating pseudocode and design ideas into a functional C++ program.

## How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

This project helped me improve how I organize and structure my code. I focused on using descriptive names, comments, and separate functions to make the program easier to understand and troubleshoot. I also learned the importance of keeping different parts of a program organized so changes can be made without rewriting the entire application. Moving forward, I plan to continue using these practices to create programs that are easier to maintain, modify, and expand as requirements change.
